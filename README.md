# がくりょくしんだん（小4・算数/社会 単元別判定テスト）

小学4年生の算数・社会について、**単元ごとの理解度を短時間でチェックする**タブレット向けの
判定テストアプリです。サーバー・ログイン不要。HTML/CSS/JS だけで動きます。

`kanji_drill`（毎日反復する漢字ドリル）とは役割が違い、こちらは**診断専用**です。
日々の対策（苦手単元の学習）はアプリ化せず、市販の紙ドリルに直接書き込む方式を想定しています。

## できること

- 受験前に**「ならった単元」だけを選べる**（未習単元は出題しない。未習を出すと必ず0%になり「最優先で対策すべき単元」を乗っ取ってしまうため）。選んだ範囲は端末に記憶される
- 算数・社会の単元別に3択クイズを出題（自動採点）
- 受験終了後、**単元ごとの正答率を低い順に一覧表示**し、苦手な単元（正答率60%未満）を赤く表示
- 最も正答率が低い単元を「最優先で対策すべき単元」として提示（苦手マップ）
- 受験日つきで結果を localStorage に保存し、**同じ教科を2回目に受けると前回との比較表**（単元別の変化）を自動表示
  - 例: 夏休み初日（対策前）と夏休み終わり（対策後）で受けて、改善を確認する使い方を想定
- ホームの「まえの結果を みる」から**過去の受験結果を何度でも再表示**できる
- 結果画面の「結果を ファイルで わたす」で、**全受験履歴をMarkdownファイル化**して共有シート（AirDrop等）で渡せる。末尾に機械可読のJSONを含むので記録用・バックアップ用を兼ねる
- 「この回だけ コピー」で、表示中の回の苦手マップをテキストでクリップボードへ

## 使い方

1. ホームで「算数をはじめる」または「社会をはじめる」を押す
2. 範囲えらび画面で、**まだ習っていない単元のチェックを外す** →「このはんいで はじめる」
3. 3択で回答 → 正誤とかんたんな解説が出る → 「つぎへ」
4. 全問終わると結果画面へ。単元別の苦手マップと（2回目以降は）前回比較が出る
5. 保護者は「結果を コピー」でテキストを控えておく（あとからホーム →「まえの結果を みる」でも再表示可）

## タブレットで使う

```bash
cd gakuryoku_shindan
python3 -m http.server 8000
# 同じWi-FiのタブレットのブラウザからPCのIP:8000 を開く
```

Safariの共有ボタン →「ホーム画面に追加」でアプリのように起動できます（オフライン対応）。
`file://` で直接開くと service worker が動かないため、`http://`/`https://` で開いてください。

## データについて

- 受験履歴は**その端末のブラウザ（localStorage）だけ**に保存されます。端末を初期化すると消えるため、
  受験のたびに「結果を ファイルで わたす」で書き出して保管してください（これがバックアップになります）
- 単元・問題の追加は `sansu_data.js` / `shakai_data.js` を編集してください（`unit` フィールドで結果画面の集計単位が決まります）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み（ホーム／範囲えらび／クイズ／結果／履歴） |
| `style.css` | 見た目 |
| `app.js` | 出題・採点・単元別集計・履歴比較のロジック |
| `sansu_data.js` | 算数の問題バンク |
| `shakai_data.js` | 社会の問題バンク |
| `manifest.webmanifest` / `sw.js` | PWA（ホーム追加・オフライン） |
| `icons/` | ホーム画面アイコン |

夏休みの苦手克服プランの一環（`reports/kids/算数図形_改善プログラム_202608.md` 参照）。

洗い出すために、算数・社会の全単元を横断してチェックする目的で作成した。
